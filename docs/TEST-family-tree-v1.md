## 5. 问题与风险

| 级别 | 说明 | 建议 |
|------|------|------|
| 中 | 默认管理员密码仅适合本地 | 上线改 `ADMIN_PASS` / 轮换 |
| 中 | 配偶入谱若无子女且无 parent，不作为树根（设计如此） | 在成员详情/管理列表维护 |
| 低 | vue3-tree-org 在极老 WebView 需真机验证缩放手势 | 参考 DEPLOY 微信章节 |
| 低 | 代数侧栏依赖 DOM 测距同步，极快拖动时可能有 1 帧延迟 | 可接受；节点角标「N世」作兜底 |
| 低 | multer 1.x 有已知漏洞告警 | 可后续升 2.x |
| 已修 | 世系 mapNode 误把 `gender` 写成 `generation`，且生卒嵌套导致节点只显示姓名 | v1.1 已扁平化字段并展示性别/生年/在世 |

**无阻塞级高危未修项。**

---

## 6. 优化建议

- 数据量大时为树接口加缓存或按根分页
- 增加备份 cron 失败告警邮件
- 可选接入微信 JS-SDK 自定义分享卡片
